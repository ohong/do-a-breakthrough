# Coordinator observations

These are independent lemmas and candidate mechanisms recorded during the
first research wave. They are not a solution.

## 1. Coordinate accounting

Let \(N=2^d\). For coordinate \(i\), let

\[
c_i=\left|\{v:v_i=0,\ \sigma(v)_i=1\}\right|.
\]

Because \(\sigma\) is a bijection, the same number of requests change bit \(i\)
from \(1\) to \(0\).

**Lemma 1 (`proved`).** In any routing, if \(p_i\) and \(q_i\) are the numbers
of used \(0\to1\) and \(1\to0\) arcs in dimension \(i\), then

\[
p_i=q_i=c_i+r_i
\]

for an integer \(r_i\) satisfying
\(0\le r_i\le N/2-c_i\). Consequently,

\[
\sum_v |P_v|
=\sum_v \operatorname{dist}(v,\sigma(v))+2\sum_i r_i.
\]

**Proof.** For each individual path, the number of \(0\to1\) traversals minus
the number of \(1\to0\) traversals in coordinate \(i\) equals the target bit
minus the source bit. Summing over all sources gives zero because a
permutation preserves the number of zero and one target bits. Every request
that changes \(0\to1\) needs at least one such traversal, so
\(p_i=q_i\ge c_i\). Write their common value as \(c_i+r_i\). There are only
\(N/2\) arcs in either direction of dimension \(i\), which gives the upper
bound. Summing coordinate traversals proves the length identity.

**Corollary (`proved`).** If \(c_i=N/2\), every route crosses coordinate \(i\)
exactly once when its endpoints differ in that coordinate and never makes an
extra backtrack in that coordinate. Every directed dimension-\(i\) arc is
used.

This is a useful rigidity test for near-antipodal candidates.

## 2. Slack as displacement from the antipode

Let \(A(v)=\bar v\) be the antipodal map and set
\(\rho=A\circ\sigma\). Define the total directed-arc slack

\[
S=dN-\sum_v\operatorname{dist}(v,\sigma(v)).
\]

**Lemma 2 (`proved`).**

\[
S=\sum_v\operatorname{dist}(v,\rho(v)).
\]

**Proof.** For every \(v,y\in\{0,1\}^d\),
\(\operatorname{dist}(v,A(y))=d-\operatorname{dist}(v,y)\). Apply this with
\(y=\sigma(v)\) and sum.

Hence \(S=0\) only for \(\sigma=A\). If \(S=2\), then \(\rho\) fixes every
vertex except for one transposition of adjacent vertices: a nonidentity
permutation moves at least two vertices, and equality forces each moved
vertex to travel distance one.

## 3. A proved near-antipodal family

Fix any coordinate order \(1,\ldots,d\). The standard antipodal path \(B_v\)
starts at \(v\) and flips the coordinates in that order. The family
\((B_v)_v\) uses every directed cube arc exactly once.

**Lemma 3 (`proved`).** If \(\rho\) is a product of disjoint transpositions
\((a,b)\), each with \(\operatorname{dist}(a,b)=1\), then
\(\sigma=A\circ\rho\) satisfies Szymanski's conclusion.

**Proof.** For a transposed pair \(b=a\oplus e_j\), the base paths \(B_a\) and
\(B_b\) meet at the vertex where \(B_a\) has just flipped coordinate \(j\)
and \(B_b\) is about to flip it. Exchange their suffixes at this common
vertex. This sends \(a\) to \(A(b)\) and \(b\) to \(A(a)\). It merely
recombines two globally arc-disjoint base paths. The resulting walks contain
the opposite dimension-\(j\) arcs as an immediate two-arc directed cycle;
delete that cycle to obtain paths. Since the transpositions are vertex
disjoint, the recombinations use disjoint pairs of base paths and can be done
simultaneously. All untouched \(B_v\) still route \(v\) to \(A(v)\).

In particular, every slack-two permutation is routable. More generally, this
settles a sparse near-antipodal family, not all permutations of a given slack.

## 4. Tail-switch framework

The base antipodal paths give a useful switching picture. If several base
paths share a vertex, their outgoing suffixes can be permuted at that vertex
without creating an arc conflict. Thus a cycle of \(\rho\) can be implemented
whenever all corresponding base paths share a common switching vertex.

For the fixed coordinate order, the starts of base paths passing through a
vertex \(x\) are

\[
\{x\oplus M_0,x\oplus M_1,\ldots,x\oplus M_d\},
\]

where \(M_j\) is the mask of the first \(j\) coordinates. This is a
\((d+1)\)-vertex prefix chain.

The tempting claim that connectedness of the pairwise-intersection graph
suffices is **false as stated**: switches occur in a fixed order along each
base path, and a connected one-use switching network need not realize every
permutation. The missing deliverable is a precise characterization of the
endpoint permutations generated by these ordered switches, or a
rearrangeable switching subnetwork. Until then this route is `conjectured`.

## 5. Metric-dual obstruction

For any nonnegative length \(\ell(a)\) on each directed arc, every valid
routing must satisfy

\[
\sum_v \operatorname{dist}_\ell(v,\sigma(v))
\le \sum_a \ell(a).
\]

This is `proved`: each route costs at least its \(\ell\)-shortest-path
distance, while arc-disjointness bounds the total used cost by the cost of all
arcs.

A strict reverse inequality would be a concise fractional-infeasibility
certificate and therefore a complete counterexample. Ordinary cut weights are
known to pass by cube isoperimetry; a useful search must allow genuinely
non-cut directed metrics. No violating metric is currently known.

## 6. Product and skew-product closure

**Lemma 4 (`proved`).** Suppose a permutation \(\tau\) of \(Q_q\) is routable.
For every \(y\in Q_q\), suppose a permutation \(\alpha_y\) of \(Q_p\) is
routable. Then the skew-product permutation

\[
\pi(x,y)=(\alpha_y(x),\tau(y))
\]

of \(Q_{p+q}=Q_p\square Q_q\) is routable.

**Proof.** First, inside each \(Q_p\)-fiber indexed by \(y\), route
\((x,y)\) to \((\alpha_y(x),y)\) using a copy of the routing for
\(\alpha_y\). Different fibers are arc-disjoint. For each fixed
\(x'\in Q_p\), the intermediate vertices with first coordinate \(x'\) contain
exactly one commodity from every \(y\)-fiber, because each \(\alpha_y\) is a
bijection. Route those commodities from \((x',y)\) to
\((x',\tau(y))\) using a copy of the routing for \(\tau\). Different
\(x'\)-fibers are arc-disjoint. The first phase uses only the first \(p\)
dimensions and the second only the last \(q\), so the two phases share no arc.

The ordinary Cartesian-product closure is the special case
\(\alpha_y=\alpha\). This settles permutations respecting a nontrivial cube
block system. It does not handle a general permutation, whose target
\(Q_q\)-coordinate may depend on both \(x\) and \(y\).

## 7. A Beneš-style sufficient induction

Fix a coordinate and pair the two source vertices on every matching edge;
pair the two target vertices the same way. Make a bipartite multigraph whose
left vertices are source pairs, whose right vertices are target pairs, and
whose edges are the \(2^d\) commodities. Every vertex has degree two, so every
component is an even cycle. Alternately color each cycle \(0,1\).

The color assigns a commodity to one of the two \((d-1)\)-subcubes. At every
source pair and every target pair there is exactly one commodity of each
color, so each color induces a permutation between the pair indices. Route
those two permutations inside the two subcubes by induction.

At a source pair, the color assignment is either:

- **straight**, requiring no matching arc before the recursive route; or
- **swapped**, requiring both opposite matching arcs.

The same dichotomy holds at the corresponding target pair after the recursive
route. Therefore the construction is arc-disjoint provided that, for every
physical matching edge indexed by \(x\), the source pair \(I_x\) and target
pair \(O_x\) are not both swapped.

Each cycle has two alternating colorings. Choosing between them toggles the
straight/swapped state at every vertex of that cycle. The no-double-swap
conditions are consequently a 2-SAT instance on the cycle choices.

**Sufficient induction lemma (`proved`).** If this 2-SAT instance is
satisfiable for some coordinate, then the permutation is routable assuming
Szymanski's conclusion in dimension \(d-1\).

The live falsifiable claim is that every permutation has a coordinate with a
satisfiable instance. This is only `conjectured`. An unsatisfiable instance
would refute this restricted Beneš embedding, not Szymanski's conjecture:
general paths may cross the chosen cut more than at the first and last step.
